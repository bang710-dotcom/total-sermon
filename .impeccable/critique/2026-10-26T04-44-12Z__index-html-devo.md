**디자인 고유성**: 뼈대는 이 사역에서 나왔고 겉모습은 일반 입력 양식이다. 카드 순서(관찰하기 → 묵상을 돕는 질문 → 묵상하기 → 적용하기 → 오늘의 기도)는 대학부가 손에 드는 묵상집 하루치 4쪽과 같다 — 다른 앱에서는 나올 수 없는 구조다. 그런데 화면은 ISO 날짜 + 같은 무게 입력칸 8개 + 본문연구 패널을 빌려 온 본문(도구줄, 스트롱 점선 밑줄 121개)이라 「묵상집 한 장」이 아니라 「연구 도구 옆 설문지」로 읽힌다.

**탐지기**: 정적 검사 0건(이 화면은 거의 JS 가 그린다). 화면 위 검사 4건 — 입력칸 네 개의 안내문(「본문의 흐름을 요약해 보세요」 등)이 브라우저 기본 회색 3.4:1.

**한 줄 인상**: 오늘 본문이 바로 열리는 첫 순간은 좋은데, 그다음은 숙제처럼 쌓인 빈칸이고, 쓴 답을 지켜 주는 장치가 없다.

**잘된 점**
1. 하루치 구성이 인쇄 묵상집 4쪽과 같은 순서 — 목사님이 보는 것과 학생들이 든 것이 일치한다.
2. 데스크탑에서 본문이 질문 옆에 붙어 있고(sticky), 오늘 날짜로 열리며 머리줄 설명 자리에 그날 본문·제목이 나온다.
3. 답은 성경앱 노트(정본)에 쓰고 시트에 사본, 실패하면 대기열 — 같은 책 예화도 조용히 붙는다.

**우선 문제**
1. **[P1] 묵상 답이 사라질 수 있다.** 자동 저장·초안이 없고 저장은 맨 아래 단추 하나다(데스크탑 y≈1851, 폰 2720). 맥 앱이 창을 닫을 때 부르는 저장 목록(`tsbFlush`)에도 묵상은 없다(코드로 확인). 폰은 중간에 끊기는 일이 잦다. → 입력할 때마다 이 기기에 초안(IndexedDB `devoDraft:<날짜>`), 열 때 복원, `tsbFlush`에 추가, 배지에 「저장 전」, 폰에서는 저장 줄을 탭바 위에 붙이기. — `/impeccable harden`
2. **[P1] 머리줄 날짜 이동이 디자인 체계 밖이다.** ◀▶의 서식(`.ptBtn`)이 리허설 타이머 줄 안에만 걸려 있어(코드로 확인) 브라우저 기본 단추로 그려지고, 읽히는 이름이 「◀」 기호 그대로다. [오늘] 31×25, [공유] 45×25(폰 27×35, 41×35)로 손가락 기준에 못 미친다. 달력 [지우기]는 위의 깨진 상태를 만든다. → `.btn sub` + 선 아이콘 화살표, 이름표 「이전 날」·「다음 날」, 「10월 26일 (월)」 표시, [지우기] 숨김, 터치 44px. — `/impeccable polish`
3. **[P1] 아이패드에서 본문과 질문이 나란히 서지 않는다.** 두 칸 배치(`#devoBody.split`)가 맥 규칙(`hover:hover`) 안에만 있어, 아이패드는 가로 1133px에서도 본문 860px 아래에 질문이 온다(CSS로 추론, 실기기 미확인). → 아이패드 가로 블록에 같은 배치, 폰은 질문마다 「본문 보기」 접이식. — `/impeccable adapt`
4. **[P2] 「이달의」인데 한 달이 보이지 않는다.** 빈 날 안내는 「(주일은 쉽니다)」 하나뿐이라 수요일에도 그렇게 말한다(코드로 확인). → 빈 날에는 가장 가까운 앞뒤 묵상 날짜 [← 10/24 (토)] [10/27 (화) →], 주일과 「일정 없음」 구분, [시리즈 계획에서 묵상 일정 만들기]. 달력에 묵상 있는 날 점, 시리즈 이름 표시. — `/impeccable onboard`
5. **[P2] 본문이 읽기보다 연구 도구로 보인다.** 점선 밑줄 121개와 역본·①구조·②노트·⊞2분할 도구줄. → 묵상 화면에서는 점선을 숨기고, 본문을 종이 토큰(검색 상세의 `.dpPaper`처럼)으로, 도구줄은 [연구 도구] 하나로 접기. — `/impeccable quieter`

**사용자 유형별 위험 신호**
- **Casey(폰, 한 손, 아침)**: 공유·날짜 이동이 화면 맨 위(y≈105)라 엄지가 닿지 않는다. 고정 영역(앱 머리 52 + 머리줄 105 + 탭바 57 = 214px) 때문에 키보드를 올리면 쓸 자리가 아주 좁다. 저장은 2,735px 스크롤 끝.
- **Sam(키보드·화면 읽기)**: ◀▶가 기호로 읽힌다. 날짜 칸에서 Enter로 달력이 안 열린다. 답 입력칸 넷에 이름표가 없다. 카드 제목이 `<b>`라 제목 이동으로 못 찾는다. 날짜가 바뀌어도 알리지 않는다.
- **Jordan(처음 쓰는 사람)**: ①▦구조·②✎노트·⊞2분할에 설명이 없다. 「적용」 칸이 둘(적용 질문의 답, 적용하기)이다.
- **목사님 — 새벽에 오늘 묵상을 확인하고 단톡방에 공유**: 폰은 탭바 [묵상] 한 번이면 오늘이 열려 좋다. 그러나 공유 글은 「[오늘의 묵상] 2026-10-26 / 본문: 수 11:1-9 — 하솔 연합군 / [관찰]…」 — 요일 없음, 「수」 약어 그대로, 시리즈 이름·본문 글·링크 없음, 다른 날을 보고 있어도 「오늘의 묵상」. 공유 단추는 머리줄에서 가장 작은 링크다.

**작은 관찰**
- 데스크탑에서는 머리줄이 붙어 있지 않아 내리면 날짜·본문 맥락이 사라진다.
- 예화 카드가 「오늘의 기도」와 저장 단추 사이에 끼어 흐름의 끝을 끊는다.
- 동기화로 새 묵상이 들어와도 다시 그리지 않는다(날짜를 옮겨야 보임).
- 그날 본문이 12.5px 설명 자리에 있어 가장 작은 글자 중 하나다.
- 새벽에 화면 맨 위에 설교 작성용 「다른 기기에서 작성 중인 원고」 배너가 뜨면 묵상과 상관없는 경고로 하루가 시작된다(설교 작성 우선 문제 2와 같은 원인).
