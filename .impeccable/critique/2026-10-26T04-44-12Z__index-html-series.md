**디자인 고유성**: 내용은 이 제품의 것, 틀은 흔한 마법사. 선택지 카드(핵심메시지 띠, 대지마다 근거·적용, 누르면 본문이 열리는 성구 알약, 서랍 예화, 주간 묵상 범위)와 「소외된 본문 — 다음 시리즈 후보」 칩은 다른 제품에 없다. 반면 왼쪽 폼 · 오른쪽 창 · 알약 타임라인 · 「미요청 → 초안 → 확정」 글자 상태 · 같은 무게 단추 줄은 덧붙여 온 관리 도구다.

**탐지기**: 정적 검사는 긴 줄표 5곳(마법사 안내·칸 이름)뿐. 화면 위 검사는 요청사항 칸(`#sp_note`) 안내문 3.4:1(브라우저 기본 회색). 박힌 상태 색은 JS가 그리는 인라인 색이라 정적 검사가 못 잡았다 — 디자인 검토가 실측으로 찾았고 코드로 확인했다(`spStageHtml`·`spTimelineHtml`의 #8fe6b0·#ffc24d·#7fc4ff).

**한 줄 인상**: 고르는 카드는 이 앱에서 가장 공들인 부품인데, 고르는 날의 흐름(어디까지 왔나, 어디서 확정하나, 날아가지 않나)이 그 카드를 받쳐 주지 못한다.

**잘된 점**
1. 공용 선택지 카드(v620) — 아무 곳이나 눌러 고르고, 다듬은 내용이 고른 카드에 바로 보이고, 성경 참조 경고가 카드 안에 붙는다.
2. 정직한 상태 모델 — 「변경됨·재확정 필요」 감지, 미선택은 미래설교 보관함으로, 주간범위 자동 교정(v649).
3. 확정한 카드는 풀컬러 「✓ 확정」, 나머지는 흑백으로 접히고 [이 주제로 작성하기 →] — 좋은 마무리.

**우선 문제**
1. **[P1] 묵상 단계 단추 줄이 1024~1133px에서 넘친다.** 단추 6개 줄(`.toolrow`)에 줄바꿈이 없어(코드로 확인) [묵상 일정 확정]이 49×117px로 짓눌려 한 글자씩 세로로 쌓이고, 금색 [묵상집 PDF 요청]은 화면 밖으로 밀리며 페이지가 옆으로 스크롤된다(1440·375px는 정상). → 줄바꿈 + 주 단추 한 줄 전체, 미리보기·배경 테마·인쇄는 「묵상집 ▾」 메뉴 하나로. — `/impeccable layout`
2. **[P1] 상태 색이 다크 테마 값으로 박혀 있다.** 라이트 테마 실측 대비 1.31:1·1.64:1·1.87:1(세피아도 같은 값). → `--good`·`--info`·`--req` 토큰으로, ●▲는 「완료」·「요청 중」 글자로(v709 규칙). — `/impeccable colorize`
3. **[P1] [↻ 시트에서 재동기화]가 확인 없이 고른 것을 지운다.** 시트에서 시리즈를 다시 짜면서 미확정 주의 선택과 다듬기, 요청사항을 되돌린다(확인창 없음 — 코드로 확인). 오전 내내 고른 것이 한 번에 사라질 수 있다. → 남은 선택·다듬기가 있으면 확인창, 단추는 머리줄 ⋯ 메뉴로. 회차별 [확정 →]도 손가락 크기로 키우고 [재생성]과 떼어 놓기. — `/impeccable harden`
4. **[P1] 번호 체계가 두 벌이다.** 왼쪽·단추는 「① 묵상 일정 ② 설교 주제」, 타임라인은 「① 계획 ② 묵상 일정 ③ 묵상집 PDF ④ 설교 계획」, 빈 상태 문구는 「② 묵상 일정」 바로 아래에서 「① 묵상 일정」이라고 말한다. 타임라인 마디는 span이라 키보드로 못 간다. → 단계 배열 하나에서 상태·단추 이름·타임라인을 함께 만들고, 마디는 단추로. — `/impeccable clarify`
5. **[P2] 정작 고르는 자리가 비좁다.** 1024px에서 끝난 폼이 360px, 카드 창은 382px, 카드 하나 약 800px(폰 842px). 회차 하나의 선택지 4개가 3,419px에 걸치고, [확정 →]은 회차 머리줄에 있어 다시 올라가야 한다. → 묵상 일정이 생기면 왼쪽 폼을 요약 카드(책·기간·예배구분 + [계획 수정])로 접고 카드 창에 전체 폭, 회차 머리줄은 위에 붙게, 처음엔 제목·핵심메시지·대지 명제만 보이는 비교 모드. — `/impeccable layout`
